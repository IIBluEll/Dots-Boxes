## 권장 Unity 임포트 설정

- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Mesh Type: Full Rect
- Wrap Mode: Clamp
- Generate Mip Maps: Off
- Max Size: 2048

## 생성 정보

- 도구: OpenAI 기본 이미지 생성 도구
- 용도: 세로형 모바일 게임 스플래시
- 프롬프트: 첨부된 Team 5DD 로고의 정확한 `5DD` 픽셀 글자, 흰 테두리, 검은 오프셋 그림자, 청록색 본체와 자홍색 그림자를 유지합니다. 어두운 세로 9:16 배경 중앙에 로고를 배치하고, 은은한 원형 광원과 소량의 청록·자홍 픽셀만 추가합니다. 다른 문구, 게임 제목, 로딩 바, UI, 캐릭터, 워터마크는 넣지 않습니다.
