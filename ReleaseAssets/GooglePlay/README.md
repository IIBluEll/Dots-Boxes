## 출시 전 추가 준비

- 실제 게임 화면 스크린샷 최소 2장
- 게임 권장 구성: 세로형 1080 x 1920 스크린샷 3장 이상
- 권장 장면: 시작 화면, 실제 대전 화면, 승리 또는 결과 화면

스토어 스크린샷은 실제 게임 경험을 보여주도록 Unity 또는 테스트 기기에서 직접 캡처합니다.
